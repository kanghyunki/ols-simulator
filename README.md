# OLS Simulator

Next.js app: `src/components/simulator.tsx` (controls, shadcn Toggle/Button) + `src/lib/ols-engine.js` (Annex 14 OLS geometry, terrain, OSM buildings, Three.js 3D). Airport registry `src/data/airports.js` is generated by `tools/ols/gen_registry.py` in the cadip-web repo; `public/data/osm_*.js` and `public/dem/*.bin` are its per-airport data, loaded on demand.

Dev: `npm run dev`. Check: `npx tsc --noEmit -p .` and `npm run build`.
